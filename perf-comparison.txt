=========================================================
Date: 2026-07-29
Project: ~/work/bes_devel.cov
Setup: 3 variants (debug, debug-cov, release), 2897 Tupfiles, 37774 source files
Method: Full first-time parse (rm -rf .tup build-* && tup init && tup variant tup/variants/* && tup parse)
Binaries: REF = c455241c (mempool), NEW = d7afed6b (jp_alloc)

Analysis
--------
Time: jp_alloc is consistently ~6% faster. Lock-free CAS freelists avoid
mutex contention; headerless sized allocations improve cache density.

RSS: +41 MB (12%) from power-of-2 rounding. Old mempool packed objects at
exact sizeof; jp_alloc rounds up to next power of 2. tent_tree (60% waste)
and the 24-byte structs (33% waste) are the biggest contributors.

Trade-off: 6% faster parse for 12% more transient memory (freed at exit).
